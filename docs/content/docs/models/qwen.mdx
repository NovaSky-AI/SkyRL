Supported on `main` with the Megatron backend. Qwen3.8-Flash-Next has [its own page](/docs/models/qwen3_8_flash_next). Dense models also work with FSDP, and Qwen3 and Qwen-3.5 Dense work with JAX.

| Family | Sizes | Full FT | LoRA | Low precision |
|---|---|---|---|---|
| Qwen3.6 | 27B, 35B-A3B | ✅ | ✅ | INT4 QAT (35B-A3B) |
| Qwen-3.5 | Dense: 0.8B/2B/4B/9B/27B, MoE: 35B-A3B/122B-A10B/397B-A17B, VL | ✅ | ✅ | FP8 (Hopper), MXFP8 (Blackwell) |
| Qwen3 | Dense: 0.6B/1.7B/4B/8B/32B, MoE: 30B-A3B/235B-A22B | ✅ | ✅ | |

## Example scripts

Scripts are in [`examples/train/megatron/`](https://github.com/NovaSky-AI/SkyRL/tree/main/examples/train/megatron) unless linked otherwise. Prepare the data first:

```bash
uv run examples/train/gsm8k/gsm8k_dataset.py --output_dir $HOME/data/gsm8k
bash examples/train/algorithms/dapo/prepare_dapo_data.sh
```

### Qwen3.6

| Model | Task | Mode | Hardware | Script |
|---|---|---|---|---|
| 27B | DAPO | LoRA | 4x8 H200 | `run_megatron_dapo_qwen3.6_27b_lora.sh` |
| 35B-A3B | DAPO | LoRA | 4x8 H100 | `run_megatron_dapo_qwen3.6_35b_a3b_lora.sh` |
| 35B-A3B INT4 | DAPO | LoRA + INT4 QAT | 1x8 H200 | `run_megatron_dapo_qwen3.6_35b_a3b_lora_int4_qat.sh` |

The INT4 script uses the same setup as [Kimi K2.7](/docs/models/kimi): vLLM serves INT4 (W4A16), and the trainer fake-quantizes its BF16 experts onto the same INT4 grid, with TIS correcting what's left of the mismatch.
`QAT_MODE=off` disables fake-quant and TIS, as a baseline.

## Notes

- Qwen-3.5/3.6 on Blackwell: set `FLA_TILELANG=0` (fla's TileLang GDN backend aborts in the packed backward). Leave it unset on Hopper, where Triton's GDN backward is broken.
- Qwen-3.5 VL trains the vision tower and supports sequence packing and context parallelism. Set `language_model_only=true` to train text-only.
- Qwen3-235B-A22B: max TP is 4 (it has 4 KV groups).
